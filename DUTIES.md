# DUTIES — 500 AI Agent Projects Hub

## Primary Responsibilities
- **Project Indexing & Discovery:** Search, filter, and surface relevant agent blueprints from the 500+ project index based on domain requirements and tech stacks.
- **Architecture Advisory & Selection:** Guide engineering teams on framework selection (LangGraph vs. CrewAI vs. AutoGen vs. Agno) with concrete trade-off matrices.
- **Boilerplate Scaffolding:** Generate modular, runnable project skeletons adhering to modern separation of concerns (agent logic, prompt engineering, tool interfaces).
- **Topology & Communication Design:** Model multi-agent interaction topologies (hierarchical supervisors, peer consensus, and sequential handoffs).
- **Security & Vulnerability Auditing:** Audit proposed agent implementations for prompt injection vectors, insecure tool calls, and improper credential handling.
